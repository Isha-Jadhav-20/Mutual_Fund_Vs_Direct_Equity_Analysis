# Mutual Fund Vs Direct Equity Investment Trend Analysis

## Project Overview

This project analyzes and compares investment trends in Mutual Funds and Direct Equity in India using financial data.

The project uses Python, Pandas, NumPy, Matplotlib, SQL, MySQL, and Power BI to perform data cleaning, analysis, visualization, and dashboard reporting.

The main objective is to understand how Mutual Fund and Direct Equity investment trends changed over the selected period and to generate meaningful financial insights from the data.

---

## Objectives

- Analyze Mutual Fund investment trends.
- Analyze Direct Equity investment trends.
- Compare Mutual Fund AUM with Direct Equity values.
- Analyze Mutual Fund net inflow trends.
- Compare BSE and NSE equity values.
- Analyze Mutual Fund folio trends.
- Identify Mutual Fund schemes with higher average AUM.
- Create an interactive Power BI dashboard.
- Generate an automated PDF report using Python.

## Dataset Sources

### Mutual Fund Data

Mutual Fund data is based on AMFI-related financial data and contains information such as:

- Year
- Month
- Scheme Name
- AUM
- Net Inflow
- Number of Schemes
- Number of Folios

### Direct Equity Data

Direct Equity data contains market-related information including:

- Year
- Month
- BSE Equity Value
- NSE Equity Value
- Total Equity Settlement Value

Source/reference data was collected from relevant financial market sources.
